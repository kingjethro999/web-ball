claude response:
Your draft has the right instincts. It reads as a complaint, though, and an agent given complaints tends to patch the surface (swap a cylinder for a capsule) rather than fix the cause. The prompt below tells it what to build, what to avoid, how to check its own work, and what order to work in.

Some points first, because they affect how you prompt:

- **Don't ask the agent to "make nice players" out of code shapes.** That is why you got cylinders and box heads. Real character quality comes from a rigged, animated model (a skeleton with run, kick, and tackle animations), not from primitives. The prompt tells it to use a properly licensed free character model and recolor it per club kit.
- **Give it acceptance criteria.** "Player looks like a person, no dropdowns, 6 camera views" can be checked. "Make it good" can't.
- **Make it work in milestones and show screenshots.** Otherwise it will say it's done when it isn't.
- **Give it a bad-output list.** Naming what you hate (cylinders, dropdowns, website-style UI) works well.
